# BONDHU animated cartoon billboard

Open ../billboard_bondhu.html in a modern browser. Keep this folder next to the HTML. Fonts, vector cartoons, and Bangla narration work offline.

## Eight animated scenes

1. BONDHU rolls into the room; the elderly character welcomes it.
2. Bangla conversation, speaking mouths, listening waves, gestures.
3. The clock signals a reminder; the character reaches for medicine.
4. A sensor scan draws a heartbeat trace and shows health-information labels.
5. A request for help triggers SOS and a message traveling to the family's phone.
6. The person walks, the robot follows, and both stop.
7. A spoken request turns a dark room into a lit room.
8. The characters celebrate their companionship.

The characters, room, and props are custom SVG artwork, not embedded video. Movement is driven by a shared scene timeline, so pause, speed, and duration changes apply to the whole cartoon. Feature graphics are illustrative, not live readings, medical advice, or real alerts.

## Timing controls

Click “সময় ও গতি”. Each scene has an independent duration slider and number input (8–60 seconds). The global speed selector (0.5×–2×) changes both animation and audio speed. “সব দৃশ্যে” applies a duration to every scene. “ডিফল্ট ফিরিয়ে আনুন” restores defaults. Settings save in this browser where local storage is available.

Default loop length: 2 minutes 14 seconds at 1×. Changing the current scene's duration restarts that scene. Pause/resume preserves its animation position. At 2×, a 16-second scene takes 8 seconds of real time.

## Playback

Click “বাংলা ভয়েস চালু” once for sound. Browsers require interaction before playing audio.

- F: fullscreen.
- M: sound on/off.
- Space: pause/resume.
- Left/right arrows: previous/next scene.
- Add ?clean to the HTML URL to hide operator controls for billboard display/capture. Keyboard shortcuts remain available.
- Reduced-motion preferences start the cartoon paused; press Play to start.

This deliverable is animated HTML, not an exported GIF/MP4. Narration uses Microsoft Edge TTS, bn-BD-NabanitaNeural. Noto Sans Bengali fonts are included under FONT-LICENSE.txt.
